# ChronoFlow

A local-first personal time tracker for Windows 11.

## Included
Timer and manual entries, projects/tasks/tags, timesheet, calendar, dashboard and reports, Auto Tracker, idle detection, reminders, Pomodoro, tray integration, startup option, CSV/XLSX/PDF export, dark/light themes, and local SQLite storage.

## Backups
ChronoFlow supports safe SQLite backups while the app is running. Automatic backups can be enabled or disabled and scheduled for every 1/6/12 hours, daily, every 3 days, weekly, custom N hours, custom N days, or when the app exits. Choose any backup folder and how many recent backups to retain. Defaults: automatic backup ON, daily, keep 30. Manual Back up now and Restore from backup are also available.

## Windows build
Upload this repository to GitHub, open Actions, run **Build ChronoFlow for Windows**, then download the generated `ChronoFlow-Windows11` artifact. Python is not required on the PC that runs the resulting EXE.
